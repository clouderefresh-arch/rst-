# ООО «РТК» — лендинг

Одностраничный сайт сервисной и торговой компании: ремонт автотранспорта и поставка запчастей. Подольск, Климовск, доставка по РФ.

## Стек

Next.js (App Router), TypeScript, Tailwind CSS, lucide-react.

## Запуск

```bash
npm install
npm run dev
```

Продакшен-сборка: `npm run build && npm run start`.

Сайт на сервере: http://89.208.14.36:62077/

Ключи бота на этой машине лежат в `/opt/rtk/src/config/telegram.ts`. После правки выполните `systemctl restart rtk`.

## Заявки в Telegram

Форма отправляет `POST /api/lead` с полями `name`, `phone`, `carInfo`, `serviceType`, `comment`.

Откройте `src/config/telegram.ts` и вставьте:

- `TELEGRAM_BOT_TOKEN` — токен бота от @BotFather
- `TELEGRAM_CHAT_ID` — id чата, куда бот пишет заявки
- `TELEGRAM_ALLOWED_USER_IDS` — id сотрудников, которым можно смотреть заявки и менять статус. Одна строка на человека. Свой id бот присылает в ответ на `/start`

Сохраните файл и перезапустите сайт: `systemctl restart rtk`. Бот должен иметь право писать в указанный чат.

В боте: `/leads` список, `/open` только не обработанные, `/sort` сортировка. Под сообщением кнопки: сначала новые, сначала старые, по статусу, по услуге. У заявки кнопки «В работе» и «Обработана». Пока статус не «Обработана», бот напоминает о заявке. Срок первого напоминания и повтор задаются в том же файле.

Те же токен и чат можно задать в `.env.local` (скопируйте `.env.example`). Если они заданы, они важнее файла. Без токена и id страница открывается, а форма отвечает ошибкой.
